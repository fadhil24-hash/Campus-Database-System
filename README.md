# Campus Database System

A simple HTML, CSS, PHP and MySQL based Campus Dataase system.

## Features
- User Login
- Student Management
- Lecturer Management
- Admin Dashboard
- Course and Enrollment Management
- Schedule Management

## Technologies
- PHP
- MySQL
- HTML/CSS

## Database
Import the SQL file from:

campus_db.sql

## How to Run
1. Move project to htdocs in xampp folder
2. Import SQL database to phpmyadmin
3. Start Apache & MySQL in xampp control panel
4. Open localhost/campus_db in web browser
